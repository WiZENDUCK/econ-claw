# agents/

这个目录定义经研龙虾可使用的协作角色。

## 当前角色

- `scout.md`：研究前端，负责从现实问题形成研究题目
- `reviewer.md`：完整审稿视角，负责结构化批评
- `critic.md`：压力测试视角，负责击穿最脆弱点
- `defender.md`：防守与收缩视角，负责在不偏离研究本意的前提下修补
- `fixer.md`：执行修订视角，负责把问题转成具体修改动作
- `writer.md`：论文与投稿表达视角，负责把研究材料转成文字

## 使用原则

- 先判断当前任务需要哪种角色，不要同时滥用多个角色
- reviewer 更适合完整审稿
- critic 更适合做红队压力测试
- defender / fixer 应该在批评之后出场
- writer 的表达必须服从 reviewer / critic 发现的问题
