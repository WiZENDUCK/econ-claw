# rules/

这个目录定义经研龙虾在研究任务中默认遵守的规则与协议。

## 当前规则

- `research-protocol.md`：全局研究协议
- `anti-hallucination.md`：反幻觉规则
- `defender-boundary.md`：defender / fixer 边界
- `review-order.md`：审查顺序
- `data-principles.md`：数据组织原则
- `hooks.md`：关键节点 hook 说明
- `writing-boundary.md`：写作边界规则

## 使用原则

- 全局研究任务先遵守 `research-protocol`
- 出现不确定信息时优先遵守 `anti-hallucination`
- 进入防守与返修时优先遵守 `defender-boundary`
- 进入审稿时优先遵守 `review-order`
- 组织数据方案时优先遵守 `data-principles`
- 进入论文表达时优先遵守 `writing-boundary`
