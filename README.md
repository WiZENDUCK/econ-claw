# 经研龙虾

> 面向经济金融领域的严谨型 AI 研究工作流，覆盖选题、文献综述、识别设计、实证分析、论文写作与投稿质检。

## 项目定位

**经研龙虾** 是一个专为经济金融研究者打造的垂直 AI 学术工作台。

它不追求“大而全”的通用写作，而是强调三件事：

1. **领域垂直**：聚焦经济学、金融学与经管实证研究
2. **方法严谨**：重视识别设计、稳健性检验、交叉验证与审稿视角
3. **产出导向**：从研究想法出发，走到论文、报告与投稿前质检

## 我们想解决的问题

经济金融研究的难点，不只是“写出来”，而是：

- 怎样从新闻、政策、市场现象中提炼出可研究的问题
- 怎样快速定位文献、找到边际贡献
- 怎样设计可信的识别策略
- 怎样把数据、回归、表格、文字和审稿回复串成一条完整流水线

通用 AI 可以帮忙写段落，但很难真正深入经济金融研究的生产链。**经研龙虾** 希望补上这段空白。

## 核心能力蓝图

### 1. 选题雷达
- 从政策、新闻、市场异动中提炼研究问题
- 生成候选因变量、自变量、机制变量与数据源
- 提供潜在期刊方向与研究价值判断

### 2. 文献与贡献定位
- 结构化整理相关文献
- 识别研究空白与贡献点
- 生成文献综述框架与引言骨架

### 3. 识别设计医生
- 比较 DID / IV / RDD / Panel / SDID 等方法适配性
- 提示内生性风险与审稿人攻击点
- 自动生成稳健性与机制检验清单

### 4. 实证工坊
- 支持数据清洗、描述统计、回归、交叉验证与表格生成
- 强调可复现性与方法一致性

### 5. 写作与投稿工坊
- 根据结果生成摘要、引言、结果解读、cover letter 与 response letter
- 支持中英文写作、翻译与润色

### 6. 审稿人模式
- 模拟审稿意见
- 进行逻辑检查、质量评分与对抗式修订

## 与现有工作流的关系

本项目将整合并重构既有的经济学研究工作流能力，重点把原本偏工程化、偏命令式的研究模板，升级为：

- 更适合演示与参赛的产品化入口
- 更适合经济金融研究者理解的任务型界面
- 更强调研究全过程协作的垂直智能体系统
