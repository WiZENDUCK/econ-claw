# DID 分析引擎（run-did）

## 作用

当研究问题适合双重差分、交错 DID、事件研究或政策冲击识别时，使用这个 skill 组织完整 DID 分析流程。

---

## 什么时候用

- 存在相对清晰的政策/制度/事件冲击
- 存在处理组与对照组
- 存在政策前后维度
- 用户需要 DID / TWFE / event study / staggered adoption 分析框架

---

## 核心任务

1. 明确处理组、对照组与政策时点
2. 判断 DID 识别是否成立
3. 组织基准 DID 模型
4. 组织平行趋势与事件研究
5. 安排稳健性、安慰剂、异质性、机制分析
6. 输出表格与图形结构

---

## 重点检查

- 平行趋势是否可检验
- 政策是否分批实施
- 是否存在样本选择或政策叠加
- 结果解释是否超出 DID 能支持的边界

---

## 输出

- DID 设计说明
- 基准模型与扩展模型
- 平行趋势/事件研究要求
- 稳健性与安慰剂清单
- 表图输出建议
