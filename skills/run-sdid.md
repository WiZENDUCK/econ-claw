# SDID 分析引擎（run-sdid）

## 作用

当研究涉及少量处理单元、异质处理效应或传统 DID 识别压力较大时，使用这个 skill 组织合成双重差分分析。

---

## 什么时候用

- 传统 DID 平行趋势压力较大
- 处理组较少、对照组较多
- 用户需要 synthetic DID / 合成控制增强版本

---

## 核心任务

1. 判断 SDID 相对 DID 的必要性
2. 组织权重、处理前拟合与主估计
3. 安排与 DID / SC 的对照展示
4. 组织推断与稳健性检查

---

## 输出

- SDID 适用性判断
- 估计与展示框架
- 与传统 DID 的比较建议
