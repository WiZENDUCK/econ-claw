# RDD 分析引擎（run-rdd）

## 作用

当研究设计依赖阈值、断点、评分规则或制度门槛时，使用这个 skill 组织断点回归分析。

---

## 什么时候用

- 存在明确 cutoff / threshold
- 处理状态由阈值附近规则决定
- 用户需要 sharp / fuzzy RDD 框架

---

## 核心任务

1. 明确 running variable 与 cutoff
2. 判断 sharp / fuzzy 设计
3. 组织局部线性估计与带宽选择
4. 安排密度检验、协变量连续性、伪断点检验
5. 组织图形展示与局部效应解释

---

## 重点检查

- 是否存在断点操控
- 断点附近样本是否足够
- 结论是否被错误外推

---

## 输出

- RDD 设计说明
- 主估计与稳健性结构
- 图形与诊断检验清单
